# Blog seeds

Raw material for blog posts — **not** finished posts.

Capture insights, challenges, and ideas here *while* the infra work is fresh.
When it's time to write, the finished post is authored elsewhere (Obsidian or the
blog repo), which is the single source that publishes. This folder is upstream
feedstock: browse a seed, mine it for granular ideas, carry those over, and write
there.

## Layout

- `seeds/<slug>.md` — one seed per idea. Copy `_template.md` to start.
- `_template.md` — the skeleton.

Upgrade a seed to a folder (`seeds/<slug>/index.md` + images) only if it needs
screenshots.
